# Полное описание функций Geometrc_lib
Здесь предоставлено полное описание функций.
## Модуль `circle.py`
### `area(r)`
Использована формула `S = πr²`.\
Описание:
```
Возвращает площадь круга.
    
        Параметры:
                r (double): радиус круга
    
        Возвращаемое значение:
                area (double): площадь круга

        Пример:
                >>> area(10)
                314.1592653589793
```
### `perimeter(r)`
Использована формула `P = 2πr`.\
Описание:
```
Возвращает периметр круга.
    
        Параметры:
                r (double): радиус круга
    
        Возвращаемое значение:
                perimeter (double): периметр круга

        Пример:
                >>> perimeter(10)
                62.83185307179586
```
## Модуль `square.py`
### `area(a)`
Использована формула `S = a²`.\
Описание:
```
Возвращает площадь квадрата.
    
        Параметры:
                a (double): длина стороны квадрата
    
        Возвращаемое значение:
                area (double): площадь квадрата

        Пример:
                >>> area(10)
                100
```
### `perimeter(a)`
Использована формула `P = 4a`.\
Описание:
```
Возвращает периметр квадрата.
    
        Параметры:
                a (double): длина стороны квадрата
    
        Возвращаемое значение:
                perimeter (double): периметр квадрата
                
        Пример:
                >>> perimeter(10)
                40
```
## Модуль `rectangle.py`
### `area(a, b)`
Использована формула `S = ab`.\
Описание:
```
Возвращает площадь прямоугольника.
    
        Параметры:
                a (double): длина прямоугольника
                b (double): ширина прямоугольника
    
        Возвращаемое значение:
                area (double): площадь прямоугольника
            
        Пример:
                >>> area(10, 20)
                200
```
### `perimeter(a, b)`
Использована формула `P = 2(a + b)`.\
Описание:
```
Возвращает периметр прямоугольника.
    
        Параметры:
                a (double): длина прямоугольника
                b (double): ширина прямоугольника
    
        Возвращаемое значение:
                perimeter (double): периметр прямоугольника
            
        Пример:
                >>> perimeter(10, 20)
                60
```
## Модуль `triangle.py`
### `area(a, h)`
Использована формула `S = ½ah`.\
Описание:
```
Возвращает площадь треугольника.

        Параметры:
                a (double): длина стороны треугольника
                h (double): длина высоты треугольника, опущенная из вершины на сторону длины a

        Возвращаемое значение:
                area (double): площадь треугольника

        Пример:
                >>> area(10, 20)
                100
```
### `perimeter(a, b, c)`
Использована формула `P = a + b + c`.\
Описание:
```
Возвращает периметр треугольника.
    
        Параметры:
                a (double): длина первой стороны треугольника
                b (double): длина второй стороны треугольника
                c (double): длина третьей стороны треугольника
    
        Возвращаемое значение:
                perimeter (double): периметр треугольника

        Пример:
                >>> perimeter(10, 20, 30)
                60
```
