# Geometric_lib
## Общее описание 
Данная библиотека предоставляет удобный инструментарий для вычисления геометрических параметров базовых фигур (круг, квадрат, прямоугольник, треугольник): площади и периметра.
## Описание функций
|Модуль|Функция|Краткое описание|Полное описание|
|------|-------|----------------|---------------|
|`circle.py`|`area(r)`|Считает площадь круга по радиусу|[Описание](./functions.md#arear)|
|`circle.py`|`perimeter(r)`|Считает периметр круга по радиусу|[Описание](./functions.md#perimeterr)|
|`square.py`|`area(a)`|Считает площадь квадрата по стороне|[Описание](./functions.md#areaa)|
|`square.py`|`perimeter(a)`|Считает периметр квадрата по стороне|[Описание](./functions.md#perimetera)|
|`rectangle.py`|`area(a, b)`|Считает площадь прямоугольника по 2 соседним сторонам|[Описание](./functions.md#areaa-b)|
|`rectangle.py`|`perimeter(a, b)`|Считает периметр прямоугольника по 2 соседним сторонам|[Описание](./functions.md#perimetera-b)|
|`triangle.py`|`area(a, h)`|Считает площадь треугольника по стороне и опущенной на нее из противолежащей вершины высоте|[Описание](./functions.md#areaa-h)|
|`triangle.py`|`perimeter(a, b, c)`|Считает периметр треугольника по 3 сторонам|[Описание](./functions.md#perimetera-b-c)|
